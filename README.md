## 🎯 Motivação e Propósito

Este repositório representa a base fundamental do desenvolvimento web. O propósito deste projeto foi aplicar na prática os conceitos de **Estrutura (HTML)** e **Apresentação (CSS)**.

Ele resolve o problema de criar presença digital simples, servindo como exercício para entender como os navegadores interpretam o código, a importância da semântica das tags para acessibilidade e como o modelo de caixa (Box Model) do CSS funciona para posicionar elementos na tela.

## 🛠️ Tecnologias Utilizadas

Por ser um projeto de fundamentos, a stack é composta pelas tecnologias nativas da web:

* **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Utilizado para marcação semântica (cabeçalhos, parágrafos, listas, links e imagens).
* **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Utilizado para cores, tipografia, espaçamentos (margins/paddings) e alinhamentos básicos.
* **Git:** Para versionamento e histórico de alterações do código.

## 📦 Instalação e Execução

Este é um projeto estático, o que significa que não requer compilação ou instalação de dependências complexas (como Node.js).

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/DouglassenG/projeto_1.git](https://github.com/DouglassenG/projeto_1.git)
    ```

2.  **Acesse o diretório:**
    ```bash
    cd projeto_1
    ```

3.  **Para visualizar:**
    * Localize o arquivo `index.html` na pasta raiz.
    * Dê um duplo clique para abri-lo em seu navegador padrão (Chrome, Firefox, etc).
